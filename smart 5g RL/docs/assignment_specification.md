# Assignment Specification

## Context

You are designing and evaluating a policy for 5G RAN resource allocation across eMBB, URLLC and mMTC traffic classes.

## Scope

The project is progressive. Teams can target one of four grading levels:

- Foundation
- RL Core
- Advanced RL
- Research Extension

This assignment runs in open-project mode (no fixed timeline).

## Mandatory Outputs

1. Research report
2. Reproducible code repository
3. Working simulator
4. At least 3 non-RL baselines
5. At least 1 RL algorithm
6. Comparative experiments
7. Ablation study
8. Final presentation
9. Synthetic data generation module and documentation

## Level Definitions

## Level 0 - Understanding

Deliverable: research brief.

Students must explain:

- 5G slicing
- eMBB, URLLC, mMTC
- QoS, throughput, latency, packet loss
- Why allocation is challenging
- Why RL may help

## Level 1 - Simulator

Deliverable: environment documentation and runnable simulator.

Minimum components:

- Time-step loop
- Synthetic traffic generation
- Resource allocation interface
- Transmission update
- QoS metrics update

Synthetic data must be generated by code (not manually created files only).

## Level 2 - Baselines

Deliverable: baseline benchmark report.

Required baselines:

- Random
- Round Robin
- Priority-based

Plus one:

- Proportional allocation or equivalent

## Level 3 - RL Formulation

Deliverable: MDP design note.

Students must justify:

- State variables
- Action representation
- Reward formulation
- Constraints handling

## Level 4 - RL Implementation

Deliverable: training and evaluation package.

Possible choices:

- Q-learning (simplified)
- DQN
- PPO

## Level 5 - Research Extension

Choose one extension:

- Dynamic traffic profiles
- Channel fading model
- Constrained optimization perspective
- Multi-agent RL
- Network slicing extension
- Other approved direction

## Integrity Rule

Do not submit only an off-the-shelf PPO run. All modeling choices must be justified and compared against baselines.

Do not train/evaluate on hidden proprietary traces without a reproducible synthetic alternative.
