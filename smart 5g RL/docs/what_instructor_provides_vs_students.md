# Instructor Provides vs Student Implements

## Instructor Provides

- Problem definition
- Simulator skeleton specification
- User model interface
- Traffic generator interface
- Channel model interface
- Metric definitions
- Baseline interface requirements
- Evaluation protocol and reporting template
- Unit-test expectations

## Students Implement

- State representation
- Action representation
- Reward function
- RL algorithm implementation or adaptation
- Training strategy
- Hyperparameter tuning
- Experimental campaign
- Analysis and discussion

## Rationale

This separation ensures the project remains a real research and engineering exercise, rather than a one-click RL demo.
