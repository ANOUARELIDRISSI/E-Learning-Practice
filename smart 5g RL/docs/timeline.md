# Open Project Mode

No fixed timeline is required for this project.

Teams progress asynchronously and are evaluated on completed technical milestones, evidence quality, and reproducibility.

## Recommended Milestones (Order Only)

1. Problem understanding and assumptions
2. Simulator implementation
3. Baseline implementation and verification
4. MDP design and reward justification
5. RL implementation and comparison
6. Ablation and robustness experiments
7. Final report and presentation

## Acceptance Logic

- A milestone is considered complete only when code, experiment output, and written analysis are all provided.
- Teams can move to next milestone only after baseline quality checks pass.
