# Deliverables Checklist

## Mandatory

- Research report
- Public or shareable repository
- Setup instructions
- Reproducible run commands
- Synthetic data generation code and config
- Baseline implementations
- RL implementation
- Evaluation results
- Ablation study
- Final presentation

## Reproducibility

- Fixed random seeds
- Dependency file
- Environment description
- Scripted experiment entry points
- Clear output folder structure

## Minimum Quality Controls

- Unit tests for key simulator logic
- Basic sanity checks on metrics
- Result tables with means and variances
- Plots with axis labels and units
