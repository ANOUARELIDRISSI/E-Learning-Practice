# Student Level Guide

## Level 1 - Foundation

Implement:

- Simplified 5G simulator
- Synthetic data generator for traffic and channel conditions
- Random allocation
- Round Robin
- Priority-based allocation

No RL required.

## Level 2 - RL Core

Implement:

- MDP formulation
- One RL method (Q-learning or DQN)
- Baseline comparison

## Level 3 - Advanced RL

Implement:

- PPO or equivalent advanced method
- Dynamic traffic
- Dynamic channels
- Improved reward design

## Level 4 - Research Extension

Pick one:

- Multi-agent RL
- Constrained RL
- Network slicing extension
- Multi-cell extension
- Transfer learning
- Federated RL
- Hierarchical RL

## Completion Condition

Each level must include reproducible experiments and analysis, not only implementation.

Synthetic data assumptions must be documented and versioned.
